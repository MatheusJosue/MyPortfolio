# 🚀 Portfólio — Matheus Cerqueira

> Meu portfólio pessoal: experiência, stack e projetos de um Desenvolvedor Full Stack Pleno.

🔗 **Site:** https://matheus-cerqueira.vercel.app

## ✨ Funcionalidades

- Seções de **sobre, experiência, competências e projetos**
- **Tema claro e escuro**
- **Animações** de entrada com Framer Motion
- **Responsivo**, do celular ao desktop

## 🛠️ Tecnologias

Next.js · React · TypeScript · Tailwind CSS · React Bootstrap · Framer Motion · React Icons

## 🧠 Decisões técnicas

- **Conteúdo separado dos componentes**, para atualizar experiência e projetos sem mexer no layout.
- **Componentes documentados** em [`COMPONENTS.md`](./COMPONENTS.md) e guia de personalização em [`PERSONALIZATION.md`](./PERSONALIZATION.md).

## ▶️ Como rodar

```bash
npm install
npm run dev
```
